## A. Complexity of satisfiability (validity is the complement problem)

Satisfiability and validity are inter-reducible (validity of A = unsatisfiability of not-A). NP and PSPACE: validity is then coNP- and PSPACE-complete.
Halpern-Moses Thm 6.1 says "(and thus the validity problem for S5 is co-NP-complete)" (p. 26).

### The two headline theorems (READ-TEXT)

- **Halpern-Rego Thm 3.1** (arXiv cs/0603019v1, p. 4): "For C ⊆ {r, e, t, s}, the complexity of the problem of deciding if a formula φ ∈ L_1^K(Φ) is satisfiable in M^C(Φ) is NP-complete if e ∈ C, and is PSPACE-complete if e ∉ C."
  Here r = reflexive, e = Euclidean, t = transitive, s = serial (Section 2, p. 3). So **NP-complete iff Euclidean (axiom 5) is among the conditions, else PSPACE-complete**, for the logics generated by subsets of {D, T, 4, 5}.
  Abstract and intro (pp. 1-2): "Ladner showed that the validity problem for all logics between K, T, and S4 is PSPACE-complete, while for S5 it is NP-complete. An easy modification of his argument shows that it is NP-complete for KD45 as well."
  Proof remarks (p. 4): hardness for e ∉ C "follows from Ladner's results. Ladner proves the matching upper bound if C = ∅ (the system K), C = {r} (the system T), and C = {r, t} (the system S4). Since a reflexive relation is serial, Ladner's results deal with the cases C = {r, s} and C = {r, t, s} as well. It is straightforward to modify Ladner's argument to get PSPACE-completness in the remaining cases where e ∉ C." That last sentence is a claim without proof (covers D, K4, KD4).
  Also: "it is well known (and easy to show) that if a relation is reflexive and Euclidean, then it is symmetric, transitive, and serial".
  Halpern-Rego do **not** treat symmetry (B), so KB, KDB, KTB and KB5 are outside Theorem 3.1.
- **Rybakov-Shkatov, arXiv 1910.02257, Thm 2.1** (Section 2): "Let L be a logic such that K ⊆ L ⊆ KTB. Then, L is PSPACE-hard." Their text says the interval contains "T ... KB; KDB, which is the set of formulas valid on symmetric and serial frames". Then: "As there exist polynomial-space algorithms for deciding satisfiability, and thus validity, for KB, KDB, and KTB (see, e.g., [4]), these logics are PSPACE-complete." [4] = Goré, "Tableau methods for modal and temporal logics", Handbook of Tableau Methods, 1999 (not read). Their Thm 2.1 proof is "a slight modification of Ladner's proof ... (Theorem 3.1 in [9]; see also [1], Section 6.7)" ([9] = Ladner 1977, [1] = BdRV).

## B. Model-size bounds

### S5 (READ-TEXT, Halpern-Moses p. 26-27)

"Proposition 6.2: ([Lad77]) An S5 formula φ is satisfiable iff it is satisfiable in a structure in M_1^rst with at most |φ| states." (|φ| = length of the formula.)
The proof (p. 27) gives the sharper count: take the universal model; F = set of subformulas of the form Kψ false at the start state s; for each Kψ in F pick one witness state; the new model is S' = {s} ∪ {s_ψ : Kψ in F} with the universal relation. "it follows that |S'| <= |φ|" because |F| < |Sub(φ)| <= |φ|. So the bound in terms of operators is **at most 1 + (number of distinct box-subformulas)** worlds; in terms of subformulas, at most |Sub(φ)| worlds. The universal relation means the model is just a set of valuations (a cluster).
Prop 6.3 (p. 27): same bound |φ| for KD45 in M_1^elt (Euclidean, serial, transitive).

### K5 family (READ-TEXT, Halpern-Rego Lemma 3.2, p. 4)

"A formula φ is satisfiable in M^e iff there exists some structure M such that (M, s0) |= φ, where M = ({s0} ∪ S ∪ S', π, K), and (a) S and S' are disjoint sets of states; (b) if S = empty then S' = empty; (c) K(s0) = S; (d) K(s) = S ∪ S' if s ∈ S ∪ S'; and (e) |{s0} ∪ S ∪ S'| <= |φ|."
So the shape is: a root s0 that sees S, and a cluster S ∪ S' that is universal (every state of the cluster sees the whole cluster); S' are cluster states the root does not see. Variants (p. 4): M^es: S nonempty; M^et: S' empty; M^est: S' empty and S nonempty; M^re = M^ret = M^rest (S5): s0 ∈ S (then S' empty). Proof: |F1| + |F2| <= |φ| - 1 where F1 = false box-subformulas at s0, F2 = box-subformulas Kψ that hold at s0 but KKψ fails.
This is a clean description of K5, KD5, K45, KD45, S5. KB5 is not in Halpern-Rego.

From Nagle 1981, as cited in arXiv 2307.11727 (READ-TEXT of the citing paper; Nagle's own text NOT read): Thm 3 there: every normal logic containing K5 is complete for finite Euclidean frames of one of three forms: "(a) W = {rho} consists of a singleton root and R = empty, (b) the whole W is a cluster ..., or (c) W \ {rho} is a cluster for a (unique) root rho in W such that rho R w for some w in W \ {rho} while not rho R rho". Table 2 of that paper gives frame classes: K5: W = {rho} or W = {rho} ⊔ C; KD5: {rho} ⊔ C; K45: {rho} or ({rho} ⊔ C and rho R C); KD45: {rho} ⊔ C and rho R C; KB5: {rho} or W = C; S5: W = C. (Note this table describes rooted frames by "up to bisimulation" and has the root seeing all of C for K45/KD45; Halpern-Rego's S, S' split is the finer statement for K5/KD5.) Nagle-Thomason 1985 itself: only the abstract via a search snippet (index per extension; finite axiomatizations; lattice description). The 2023 paper says "Several of the 16 combinations coincide, resulting in 6 logics: K5, KD5, K45, KD45, KB5, and S5."

Polynomial-size model property for KB5: H-S Thm 4.15 (K4B = symmetric + transitive has "the polynomial size model property"). Shape (MINE, immediate from the frame condition): symmetric + transitive frames are a disjoint union of universal clusters and isolated worlds with no successors; no source text read for the exact bound.

### Exponential lower bound for K, T, S4 (READ-TEXT, Halpern-Moses p. 28-29)

"Proposition 6.5: There is a formula φ_m^K (resp., φ_m^T, φ_m^S4) of size O(m^2) (resp., O(m), O(m)) that is K (resp. T, S4) satisfiable, but every structure in M_1 (resp., M_1^r, M_1^rt) that satisfies it has at least 2^m states."
The proof forces a binary tree of depth m whose leaves encode all 2^m truth assignments to p_1..p_m, using depth markers d_0..d_{m+1}. Formulas: depth = AND_{i=1}^{m+1}(d_i => d_{i-1}); determined = AND_{i=1}^m (d_i => ((p_i => K(d_i => p_i)) and (not p_i => K(d_i => not p_i)))); branching = AND_{i=0}^{m-1} ((d_i and not d_{i+1}) => (not K not (d_{i+1} and not d_{i+2} and p_{i+1}) and not K not (d_{i+1} and not d_{i+2} and not p_{i+1}))); φ_m^S4 = d_0 and not d_1 and K(depth and determined and branching); φ_m^K = d_0 and not d_1 and AND_{i=0}^m K^i(depth and determined and branching) (size O(m^2)); φ_m^T = d_0 and not d_1 and K^m(...).
Upper bound companion (p. 29): "We know from Theorems 3.2 and 3.4 that if a formula φ is K_n (resp., T_n, S4_n, S5_n) satisfiable, then it is satisfiable in a structure of size <= 2^|φ|."
Tree-shaped models of low depth (p. 33): "a formula φ is K_n satisfiable if and only if it is satisfiable in a structure whose graph looks like a tree of low depth (at most dep(φ))". The exponential construction does not carry over to S5 (p. 29: the formula φ_m^S4 "is not even S5 satisfiable", because the branching clause cannot hold in a universal model), consistent with Prop 6.2.
Blackburn et al.: NOT read (no ch. 6). H-S Cor 2.6: "A modal formula is K-satisfiable if and only if it can be satisfied in a strict tree" (READ-TEXT).

## C. Correspondences and the fifteen logics

### Axioms and frame conditions (READ-TEXT in three places)

Brünnler, "Deep sequent systems for modal logic" (Arch. Math. Logic), Fig. 2:
- d: serial, "forall s exists t. s -> t", axiom "box A => dia A"
- t: reflexive, "forall s. s -> s", axiom "A => dia A" (as typeset; it is the dual form of box A => A)
- b: symmetric, "forall st. s -> t => t -> s", axiom "A => box dia A"
- 4: transitive, axiom "box A => box box A"
- 5: euclidean, "forall stu. s -> t and s -> u => t -> u", axiom "dia A => box dia A"
Halpern-Rego p. 3: "reflexivity corresponds to A3, transitivity corresponds to A4, the Euclidean property corresponds to A5, and the serial property corresponds to A6" (A6 = not K(false); they treat D as consistency); Theorem 2.1 cites Fagin-Halpern-Moses-Vardi 1995.
van der Giessen et al. 2307.11727, Table 1: 5: Euclidean "wRv and wRu => vRu"; 4: transitive; d: serial; b: symmetric; t: reflexive.
SEP (READ-VIA-SUMMARY): Sec. 7 "Seriality corresponds to the axiom (D)"; Sec. 8 table "(D) serial, (M) reflexive, (4) transitive, (B) symmetric, (5) Euclidean". SEP calls the reflexivity axiom (M) and the base system with it M ("Some authors call this system T"), names systems like "M4B", and says "S5 can be formulated equivalently by adding (B) to S4". The SEP text I got does not state the number fifteen, nor the name KD45; the cube diagram is an image.

### Implications that collapse combinations

- READ-TEXT: Halpern-Rego p. 4: "a relation [that] is reflexive and Euclidean ... is symmetric, transitive, and serial, so M^{r,e} = M^{r,e,t} = M^{r,e,s} = M^{r,e,s,t}"; and "a reflexive relation is serial".
- Brünnler (p. 12, S5 clause): "Note that each modal logic has exactly one 45-complete axiomatisation, with the exception of S5, which has two": {t,4,5} and {d,b,4,5}. His Def. 9 / Fact 2: K+{t,5} does not prove box A => box box A as a rule set, and K+{b,4} does not prove dia A => box dia A, i.e. the proof rules need the redundant 4/5 to be complete.
- MINE (elementary proofs, and a brute-force check):
  - reflexive => serial.
  - reflexive + Euclidean => symmetric (xRy, xRx, so yRx) and transitive (yRx, yRz => xRz).
  - symmetric + transitive => Euclidean (xRy, xRz: yRx, yRx and xRz give yRz).
  - symmetric + Euclidean => transitive (xRy, yRz: yRx, yRx and yRz give xRz).
  - serial + symmetric + transitive => reflexive (xRy, yRx, so xRx); hence D+B+4 = D+B+5 = S5.
  - So {B,4}, {B,5}, {B,4,5} all give KB5.
  I checked by program (`scratchpad/cube.py`, all binary relations on 1-4 points, computing which of D,T,B,4,5 follow from each subset of the five): the 32 subsets fall into **exactly 15 classes**:

  | class (logic) | subsets of axioms giving it |
  |---|---|
  | K | none |
  | D (KD) | D |
  | T (KT; T implies D) | T, DT |
  | KB | B |
  | KDB | DB |
  | B = KTB | TB, DTB |
  | K4 | 4 |
  | KD4 | D4 |
  | S4 = KT4 | T4, DT4 |
  | K5 | 5 |
  | KD5 | D5 |
  | K45 | 45 |
  | KD45 | D45 |
  | KB5 = KB4 = KB45 | B4, B5, B45 |
  | S5 | T5, DT5, DB4, DB5, TB4, TB5, T45, DTB4, DTB5, DT45, DB45, TB45, DTB45 |

  This shows 15 distinct frame classes (on frames up to 4 points; implications that hold on 4 points hold in general because each condition has at most 3 universally quantified variables, plus seriality; non-implications are witnessed by frames of at most 3 points). It does not by itself prove the 15 *logics* are distinct (that needs the frames to be distinguished by formulas; this is standard, but I did not read a proof).

## D. Gödel-McKinsey-Tarski translation

Modern form (Wikipedia "Modal companion", raw wikitext read; cites Gödel 1986 pp. 300-302):
- T(p) = box p, for each propositional variable p
- T(bottom) = bottom
- T(A and B) = T(A) and T(B)
- T(A or B) = T(A) or T(B)
- T(A -> B) = box (T(A) -> T(B))
- T(not A) = box not T(A)  (from not A := A -> bottom)
"The translation is sometimes presented in slightly different ways: for example, one may insert box before every subformula. All such variants are provably equivalent in S4."
Statement: "S4 itself is the smallest modal companion of intuitionistic logic (IPC)", where the si-fragment is rho M = {A | M proves T(A)}; so A is IPC-provable iff S4 proves T(A). Semantic form: "A is valid in rho F if and only if T(A) is valid in F" for a transitive reflexive frame F and its skeleton rho F (quotient by clusters). The S4-validity of T(A) means truth at all worlds of all reflexive transitive Kripke models (S4 is sound and complete for them: Halpern-Moses Thm 2.6 is cited in Prop 6.5's proof for "S4 satisfiable iff satisfiable in a structure in M^rt").

Gödel's original (SEP "Kurt Gödel" Sec. 2.5.3, READ-TEXT of the raw page): language with operator B, system G = classical propositional logic + S4 axioms + rule "from A infer BA":
- not p := ~Bp
- p implies q := Bp -> Bq
- p or q := Bp or Bq
- p and q := Bp and Bq
(the page prints "BQ" in the last line, an evident typo for "Bq"; the clauses are applied to subformulas recursively, atoms standing for themselves, i.e. atoms are not boxed in Gödel's original form). "Theorem 12: ... IPL |- A implies G |- A'". "Gödel conjectures that the converse implication must be true, and indeed this was shown in McKinsey and Tarski 1948."
McKinsey-Tarski, J. Symbolic Logic 13 (1948) 1-15, "Some theorems about the sentential calculi of Lewis and Heyting": the original paper NOT read. A student note (Dirmeier, fu-berlin) restates their form with strict implication and "T(v_i) = not dia not v_i" (= box v_i) (garbled text extraction; SECONDARY, weak).
Cross-check use: `A` is intuitionistically valid iff the above `T(A)` (atoms boxed, implications boxed) is S4-valid. A counter-model for T(A) in S4 (reflexive transitive Kripke model) gives an intuitionistic Kripke counter-model on the same preorder, because T(p) = box p says p holds at every successor, i.e. persistent (MINE, standard; the semantic statement above is the sourced form).

## E. TPTP non-classical (NTF) syntax (READ-TEXT: arXiv 2508.09318v1 HTML text, and the TPTP language page https://tptp.org/UserDocs/TPTPLanguage/TPTPLanguage.shtml)

Box and diamond (paper Sec. 5): "The multi-modal connectives box_i and diamond_i are provided as {$box(#i)} and {$dia(#i)}. If only one modality is required, the unindexed variants {$box} and {$dia} are normally used. There are also short form unary connectives for unparameterised {$box} and {$dia}: [.] and <.>, e.g., {$box} @ (p) can be written [.] p." Language page: "In NXF the non-classical connectives are applied in a mixed higher-order-applied/first-order-functional style, with the connectives applied using @ to a ()ed list of arguments", short forms "applied directly like negation". Interpreted variants: `$alethic_modal` {$necessary}/{$possible}; `$deontic_modal` {$obligatory}/{$permissible} (and {$forbidden}); `$epistemic_modal` {$knows}/{$canKnow}; `$doxastic_modal` {$believes}/{$canBelieve}; `$temporal_instant` {$future},{$past},{$henceforth},{$hitherto}. Bare `$box` without braces is not in the text.

Logic specification: an annotated formula with role `logic`, usually first: "An NTF file must have one logic specification ... A file without a logic specification defaults to classical logic, ... error to use a non-classical connective without a preceding logic specification." Form (Sec. 5.1):

```
tff(semantics,logic,
    $modal == [ $domains     == domains_specification,
                $designation == designation_specification,
                $terms       == terms_specification,
                $modalities  == modalities_specification ] ).
```
Values: `$domains` in {$constant, $varying, $cumulative, $decreasing}; `$designation` in {$rigid, $flexible}; `$terms` in {$global, $local}. "there are no general default values for properties - it is an error if a logic specification does not specify all relevant properties." `$modalities`: a system name `$modal_system_X` or a list `[$modal_axiom_X, ...]`; multi-modal: list of `{$box(#i)} == mono_spec` pairs, with an optional leading mono spec as default for unlisted indices (paper Fig. 6).

System names: paper Table 2 and the language page agree: language page says `Sys in { K,KB,K4,K5,K45,KB5,D,DB,D4,D5,D45,M,B,S4,S5,S5U }`. Table 2 gives (as printed in the paper): K {K}; KB {K,B}; K4 {K,4}; K5 {K,5}; K45 {K,4,5}; KB5 {K,B,5}; D {K,D}; DB {K,D,B}; D4 {K,D,4}; D5 {K,D,5}; D45 {K,D,4,5}; M or T {K,M}; **B {K,B}**; S4 {K,M,4}; S5 {K,M,B,5}. Note: the table as printed gives B the same axioms as KB; this looks like a typo for {K,M,B}, but I could not check what the TPTP implementations do. `S5U` appears on the language page only (not in the paper table; meaning not read, presumably S5 with universal accessibility). Axiom names (Table 3 and language page): `$modal_axiom_K`, `_M` (box A -> A), `_B`, `_D`, `_4`, `_5`, `_CD`, `_BoxM`, `_C4`, `_C`.

Local vs global assumptions: role `hypothesis` is local, `axiom` is global, `conjecture` is local; subroles `-local`/`-global` override (e.g. `axiom-local`).

Library facts (Sec. 6.1): TPTP v9.1.0 has 215 NTF problems, "52 propositional problems", 154 theorems, 45 countersatisfiable, all normal mono-modal. The Logics Workbench format is called "a well-established format for propositional modal logic problems".

Model output: Kripke interpretations in TPTP format (Sec. 6.3.2, Fig. 11): types `$world`, `tff(w1_decl,type,w1: $world).`, role `interpretation-worlds`: `( ! [W: $world] : ( W = w1 | W = w2 ) & $local_world = w1 & $accessible_world(w1,w1) & $accessible_world(w1,w2) ... )`; role `interpretation`: `$in_world(w1, <Tarskian interpretation formula>) & $in_world(w2, ...)`. Tarskian parts use `interpretation-domain` and `interpretation-mapping`. SZS statuses: Theorem, CounterSatisfiable, etc. (paper p. on SZS, line "CounterSatisfiable - the conjecture cannot be proved from the axioms").

Example file. **I constructed this from the grammar read above; it is not copied from the TPTP library, and I could not check it against a TPTP parser.** (The only full example in the paper is the first-order Fig. 3, which I quote the logic specification and connective usage from.)

```
% Propositional S4: K axiom (a theorem) and a countermodel candidate in K
tff(semantics,logic,
    $modal == [ $domains     == $constant,
                $designation == $rigid,
                $terms       == $local,
                $modalities  == $modal_system_S4 ] ).
tff(p_decl,type, p: $o ).
tff(q_decl,type, q: $o ).
tff(k_axiom,conjecture,
    ( {$box} @ ( p => q ) ) => ( ( [.] p ) => ( [.] q ) ) ).
```
Fig. 3 of the paper (a first-order example, read) starts with `tff(semantics,logic, $alethic_modal == [ $domains == $constant, $designation == $rigid, $terms == $global, $modalities == $modal_system_M ] ).` and uses `{$possible} @ ( gets_rich(P) )`.
The TPTP library problems I tried to fetch as propositional examples (SYO, LCL) were embeddings (translated to first-order), not NTF, so I give no library example.

## G. Kripke models as text or JSON

- **Modal Logic Playground** (READ-TEXT, MPL.js lines 240-300 and API-Reference.md): a model string, "compact string suitable for use as a URL parameter". Per state, in index order, `A<comma-separated true variables>S<comma-separated successor indices>;`; a removed state is an empty slot `;`. Example: states 0 (q true; successors 0 and 2), 1 removed, 2 (nothing true; no successors) is `AqS0,2;;AS;`. Loader regex: `^(?:;|(?:A|A(?:\w+,)*\w+)(?:S|S(?:\d+,)*\d+);)+$`. Only true variables are stored. Wff JSON form: `{prop:'p'}`, `{neg:A}`, `{nec:A}`, `{poss:A}`, `{conj:[A,B]}`, `{disj:[A,B]}`, `{impl:[A,B]}`, `{equi:[A,B]}`. Model JS form: states as `{assignment:{q:true}, successors:[0,2]}` or null.
- **MDK-verifier / *SAT / Spartacus K-satisfiability output** (READ-TEXT, mdk-verifier page): DIMACS-style. First line: `<#variables> <#worlds> <#relations> <#edges>` (in the solver output prefixed by `v`). Then one line per world listing true variables as positive integers and false ones as negatives, ending with `0` (e.g. `-1 2 0`). Then one line per edge `r1 w0 w1`. Output status line `s SATISFIABLE`; world 0 is the point of evaluation. The checker answers `OK 2` (2 worlds) or `ERROR: model is incorrect`.
- **TPTP**: Kripke interpretation as TPTP annotated formulas (see E), checked by the AGMV verifier (paper).
- **MOIN** (READ-TEXT, readme): a countermodel (classical K-family and intuitionistic multi-conclusion) is written as LaTeX (`counterNK.tex`, `counterNKm.tex`, compiled into `NK+X-result.tex`); not a data format. The classical countermodel is a Kripke model; the intuitionistic one is bi-relational.
- No JSON Kripke format found in LoTREC, Carnap, Isabelle or Lean (Isabelle/Lean use their own record/structure types: Isabelle `kripke` record with `𝒲`, `𝒦 :: 'i => 'w => 'w set`, `π :: 'w => id => bool`). I did not look at teaching sites beyond these.
